Sorteio NPS

 
Pool de projetos elegíveis para a próxima campanha, mais os projetos encerrados no mês. Marque quem efetivamente vai receber a pesquisa e valide.


 

  
Critérios do NPS Aleatório

  
    
   
  1. O projeto deve estar ativo (e não ser projeto interno da PWR)
    2. 
   
  2. Não deve ter data de término prevista nos próximos 30 dias
    3. 
   
  3. No mínimo 90 dias desde a data de início
    4. 
   
  4. Não aplicado NPS (Aleatório ou Término) com a empresa nos últimos 6 meses
    5. 
   
  5. Ao classificar: o projeto tem Senior quando o Gerente de Projeto OU o Scrum Master do próprio projeto é Senior. Sem nenhum dos dois, normalmente é Gerente Sócio + Scrum Pleno, ou Gerente e Scrum ambos Sócio
    6.
